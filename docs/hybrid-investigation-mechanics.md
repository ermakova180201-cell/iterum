# ITERUM — гибридная механика расследования (рабочая концепция)

Статус: предложение на обсуждение; НЕ утверждённый полный перечень улик или готовая игровая логика.

## Принципы
- Оригинальная детективная игра с физическими материалами и веб-платформой ITERUM.
- Игрок самостоятельно сопоставляет бумажные и цифровые сведения; нет обязательной линейной цепочки конвертов.
- Важные физические улики указывают на проверки на сайте; цифровые данные меняют интерпретацию бумажных источников. Не дублировать одно и то же ради объёма.
- Фиксированные факты должны выводиться из минимум двух надёжных, по возможности независимых источников; отличать наблюдение, предположение и доказательство.
- Не использовать искусственные QR-коды и пароли на каждом документе. QR-код в приветственном письме — вход в систему. Поиск по реальным для мира игры реквизитам — предпочтительнее.
- Помощник: интерфейс, наводящие методические подсказки без сюжетных спойлеров и вымышленных фактов.
- Финал: самостоятельное заключение игрока по доказательствам; важные факты не зависят исключительно от искусственного интеллекта.

## Уже утверждено
1. Физическое приветственное письмо ITERUM с QR-кодом на платформу, пригодное для последующих расследований (на запуске доступно одно).
2. Полноценный выпуск городской газеты среди физических материалов; конкретная вёрстка, город и текст будут существенно дорабатываться. Статья о смертельном ДТП — одна из городских заметок, не обязательно на обложке. Газета НЕ должна утверждать столкновение, второй автомобиль и неустановленный механизм ДТП.
3. Анонимный заказчик присылает поручение через встроенную электронную почту ITERUM, не физическим письмом.

## Рабочий прототип цепочки
- Бумажная газета (публикация о происшествии) -> поиск соответствующей информации в архиве новостей -> сопоставление с другой доступной записью.
- Бумажный материал о семье/мероприятии -> поиск людей и дат в системе -> реконструкция временной шкалы вечера.
- Бумажный служебный документ с правдоподобными реквизитами -> проверка служебных записей в базе -> связь с событиями 28 мая.
- Физическая медицинская информация -> ограниченная проверка медпрофиля и хронологии без фантастических допущений об амнезии.
- Дополнительные материалы -> фактическая оценка действий Андрея и Центра; механизм аварии и конкретная доказательная цепь пока не утверждены.

## Функции сайта для оценки
- Существующие: почта, поиск, материалы, новости, помощник.
- Кандидаты: перекрёстные ссылки, закладки/изучено, поиск по реквизитам, ограниченный доступ к некоторым записям, финальная форма мотивированного заключения, подсказки без спойлеров.
- Все критические ветви обязаны оставаться проходимыми без случайного угадывания.
- Никаких реальных программных изменений на этом этапе не утверждено.
